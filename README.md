# FrameLedger · 影视制作预算与资产版权协同平台

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型影视制作团队，演示预算版本、成本预测、合同里程碑、资产版本、授权窗口冲突与审批审计的协同闭环。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5175，API 默认 `http://localhost:4104`。

## 业务能力

- 项目 / 季 / 交付日期与预算基线；计划、承诺、实际、预测成本四账合一
- 供应商合同额度、付款里程碑与付款暴露额
- 母版、预告、海报、音频、字幕等资产版本和 checksum 登记
- 地域、平台、有效期、版权标签冲突检测
- 预算 / 资产 / 交付审批队列和审计事件
- React 控制台支持项目切换、预算表、风险雷达、审批操作和版权资产视图

- 资产版本关联的授权证据台账：登记证据引用、SHA-256 摘要、授权方、地域/平台与有效期
- 面向待交付范围计算“已覆盖、缺证、已过期、范围不匹配”，并保留外部文件内容未验证标记
- 法务可从版权冲突、资产版本或审批上下文进入证据；证据变更和覆盖结论进入审批/审计链

当前使用内存数据，领域服务按模块设计，后续可替换 PostgreSQL、对象存储、工作流和版权方台账服务。第一版只保存证据元数据和外部引用，不抓取或验真外部文件；付款凭证默认作为辅助证据，不单独授予权利。
