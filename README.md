# FrameLedger · 影视制作预算与资产版权协同平台

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型影视制作团队，演示预算版本、成本预测、合同里程碑、资产版本、授权窗口冲突与审批审计的协同闭环。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5175，API 默认 `http://localhost:4104`。

## 业务能力

- 项目 / 季 / 交付日期与预算基线；计划、承诺、实际、预测成本四账合一
- 供应商合同额度、付款里程碑与付款暴露额
- 母版、预告、海报、音频、字幕等资产版本和 checksum 登记
- 地域、平台、有效期、版权标签冲突检测
- 预算 / 资产 / 交付审批队列和审计事件
- **授权证据台账**：登记授权合同 / 补充条款 / 付款凭证的引用、摘要校验值（sha256）、授权方、许可地域/平台与有效期。登记只保存引用与登记方自报摘要（claimed），法务对原件复核一致后才转为 verified——外部文件内容不会被凭空当成已验证
- **待交付范围覆盖核算**：按“地域 × 平台 × 日期”逐格给出已覆盖 / 缺证 / 已过期 / 范围不匹配（`全球`=地域通配、`*`=全平台、到期日含当日）；旧版本证据不自动继承到新版本
- **写入可靠性**：clientToken 幂等去重（同内容重复提交只产生一条），台账连续写入失败进入待重试日志，恢复后凭 token 补提交，不产生重复记录与重复审计
- 证据登记、核验、版本替代与覆盖结论均写入审计链；覆盖结论可随资产/交付审批留存快照，并可就缺证/过期/不匹配一键发起补证审批
- React 控制台支持项目切换、预算表、风险雷达、审批操作和版权资产视图；法务可从**资产行、版权冲突、审批队列**三个上下文进入对应证据

当前使用内存数据，领域服务按模块设计，后续可替换 PostgreSQL、对象存储、工作流和版权方台账服务。覆盖核算逻辑见 `server/src/evidence.ts`（`evaluateCoverage`），场景测试见 `server/src/evidence.test.ts`。
